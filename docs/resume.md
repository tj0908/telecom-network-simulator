## 通用版（网络技术岗 / 通信工程师）

**基于 ns-3 的通信网络性能仿真与故障分析**（个人项目，C++/Python）

- 基于 ns-3 3.41（C++）构建四节点瓶颈链路仿真拓扑，实现 TCP
  （BulkSend）与 UDP（OnOff）在 2/5/10 Mbps 瓶颈带宽下的性能
  对比，输出吞吐量、丢包率、平均时延/抖动等指标。
- 引入 FlowMonitor 在 IP 层逐流统计，并与应用层 PacketSink
  双口径交叉验证；定位一次吞吐量统计偏差（固定时间窗口导致的
  2.18 Mbps 假象），以首末包时刻复核得到与瓶颈吻合的
  1.9927 Mbps，建立"报告指标必须注明统计层级与窗口"的方法规范。
- 开展队列管理与 bufferbloat 专项实验：对比 FqCoDel、FIFO、
  DropTail 及不同队列上限共 5 种配置，以 10 ms 采样记录两层
  队列（QueueDisc + 设备队列）占用与丢弃计数，证明默认配置下
  1.27 s 高时延源于 10240 包大队列与串联设备队列的总缓冲，
  并给出时延—丢包权衡的量化结论（10 包队列时延降至 60.8 ms，
  丢包率约 +5 个百分点，吞吐不变）。
- 发现并验证 FlowMonitor 丢包统计的观测盲区（特定队列配置下
  lostPackets 为 0 而实际丢包近半），建立三层计数器对账方法
  （丢弃计数 + 结束残留 + 在途量）逐包闭合。
- 实现 Python 自动化实验矩阵与数据校验、matplotlib 可视化及
  14 项回归测试，全部结果可一键复现；完整技术文档与实验数据
  见仓库 README。

技能关键词：ns-3、C++、Python、TCP/IP、拥塞控制、队列管理
（FqCoDel/DropTail）、bufferbloat、FlowMonitor、Linux、Git
